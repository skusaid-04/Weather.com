# Weather.com

A simple weather dashboard web application that displays current weather, hourly forecast, and a 7-day forecast for any city using the [WeatherAPI](https://www.weatherapi.com/).

## Features

- Search for weather by city name
- Displays current temperature, humidity, air quality, UV index, visibility, wind speed, and chance of rain
- Shows hourly temperature chart for today
- 7-day weather forecast with icons
- Responsive and modern UI

## Technologies Used

- HTML, CSS, JavaScript
- [Chart.js](https://www.chartjs.org/) for charting
- [Font Awesome](https://fontawesome.com/) for icons
- [Google Fonts](https://fonts.google.com/) for typography
- [WeatherAPI](https://www.weatherapi.com/) for weather data

## Getting Started

1. Clone or download this repository.
2. Unzip if downloaded as a zip file.
3. Open `Weather.com.html` in your browser.

## File Structure

- `Weather.com.html` - Main HTML file
- `style.css` - Stylesheet
- `script.js` - JavaScript logic for fetching and displaying weather data
- `Weather.com.png` - Logo image

## Customization

- You can change the default city in [`script.js`](script.js) by modifying the `city` variable.
- To use your own WeatherAPI key, replace the value of `apiKey` in [`script.js`](script.js).
